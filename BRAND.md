# Brand Identity — Shiro + Saffron (白·黄)

## Brand Personality
Japanese minimalist EdTech. Calm, precise, warm. 
Approachable for beginners. Premium without being intimidating.
Design philosophy: Ma (negative space), Kanso (simplicity), Shibui (subtle beauty).

## Color Palette
--paper:       #FAFAFA   (primary background)
--paper-warm:  #EDE9E1   (warm linen, secondary background)
--moss:        #4A5240   (deep green, structure + CTA bg)
--saffron:     #D4860A   (accent, numbers, highlights)
--saffron-soft:#F5E6CC   (saffron tint for subtle fills)
--ink:         #1C1C1E   (primary text)
--ink-soft:    #3A3A3C   (secondary text)
--ink-muted:   #8E8E93   (captions, handles, metadata)
--sand:        #B8A898   (subtle dividers, tertiary text)

## Saffron Usage Rules (Critical)
- Used as accent ONLY — never as a background color
- Never use saffron on body text or subtext
- Never fill large areas with saffron

### Exact Saffron Elements by Slide Type
- Cover accent line       : 40px wide, 3px height, top-left position
- Cover tag label         : saffron color, 15px DM Mono
- Content horizontal rule : full content width 936px, 1px height
- Content slide number    : 56px DM Mono, top-left anchor
- CTA handle              : saffron color, 20px DM Mono

## Font System
Headlines : Noto Serif JP, weight 300–400
Body      : DM Sans, weight 300–500
Handle/Tag: DM Mono, weight 400
Load via  : Google Fonts CDN

## Three Template Personalities
educator   → bg #FAFAFA,  accent saffron  → Deep dives, explanations
challenger → bg #EDE9E1,  accent moss     → Opinions, myth-busting  
quicklist  → bg #4A5240,  text white      → Tips, tools, checklists

## Target Audience
Age: 16–22 | Location: India | Level: Beginner
Platforms: Instagram | Goal: Learn tech fundamentals
Tone: Friendly teacher, not corporate instructor

## Brand Do's
✓ Generous white space
✓ Strong serif headlines
✓ Warm, conversational copy
✓ One concept per slide
✓ Always include @handle on every slide

## Brand Don'ts
✗ No gradients
✗ No drop shadows
✗ No neon colors
✗ No busy backgrounds
✗ No more than 2 font weights per slide
✗ No decorative icons or clip art
